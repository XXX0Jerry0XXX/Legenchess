# 传奇棋 Legenchess

传奇棋是一款原创对称双人棋类游戏。双方先隐藏布阵，再在 `8 x 12` 棋盘上轮流消耗行动点（AP）移动、攻击和释放技能，最终消灭对方全部棋子，或通过计时、投降决定胜负。双方各保留 `8 x 3` 备战区，中间交战区为 `8 x 6`。

支持本地双人热座、局域网联机，以及初学者 / 高手 / PPO 实验版 AI。

## 快速开始

推荐方式：从 GitHub 仓库的 Releases 页下载最新 `setup.exe`，安装后双击桌面或开始菜单里的「传棋 Legenchess」快捷方式即可游玩。安装包已内置运行环境，无需额外安装 Node.js。

备选方式：直接双击仓库根目录的 `start.bat`。该脚本会自动安装依赖、在后台启动并打开浏览器，但需要本机已安装 Node.js。

## 操作说明

1. 在开始页选择本地双人、局域网联机、人机对战，或继续上一局。
2. 双方轮流在己方备战区摆放 16 枚棋子，每格最多 1 枚。
3. 布阵完成后进入 2 分钟观察阶段，先手方可在计时结束前开始第一回合。
4. 每回合获得 AP，会长存活时额外获得 4 AP，后手第一回合额外获得 1 AP。
5. 点击己方棋子选择，再选择移动、攻击或技能；同一操作模式会保留到玩家切换。
6. 回合结束切换玩家，双方各有 25 分钟独立计时。

## 人机模式

开始页可选初学者、高手、PPO 实验版，每种强度均可选择先后手，AI 会自动布阵。

- 初学者：简单的随机攻击、移动和复活。
- 高手：一步评价。
- PPO 实验版：使用已训练的策略网络，覆盖内置棋子的完整技能。

## 局域网联机

- 双方各自打开游戏，主机选择「局域网联机 → 创建房间」，页面会显示房间码与连接地址（含主机局域网 IP 与端口）。
- 客机选择「局域网联机 → 加入房间」，填写主机显示的连接地址与房间码。
- 主机执上方 A（先手）、客机执下方 B（后手）；布阵阶段双方各自只见己方棋子，提交后揭开。

## 存档与布阵预设

- 对局状态会自动保存到浏览器 `localStorage`，刷新后可继续。
- 布阵阶段可导出当前布局为 JSON 文件，也可导入之前导出的 JSON 预设。
- 旧版 8×10 存档会在棋盘中央插入两行空格，下半盘棋子向下平移两行。旧版下方布阵预设也会平移两行；新版预设包含棋盘尺寸。
